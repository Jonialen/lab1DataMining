Tarea 2.  
Otros algoritmos de aprendizaje no supervisado  

INSTRUCCIONES  

El uso de algoritmos no supervisados es ampliamente utilizado en el análisis moderno de datos, especialmente en tareas de reducción de dimensionalidad, visualización y extracción de características.  

Al finalizar esta actividad, el estudiante será capaz de comprender el funcionamiento básico de estos algoritmos, identificar sus principales usos y aplicaciones, y aplicarlos a un conjunto de datos real o simulado.  

• La actividad se realizará en grupos de 3 estudiantes. Debe inscribirse usando los grupos de canvas.  
• Todos los grupos deberán trabajar todos los algoritmos indicados.  

ACTIVIDADES  

Cada grupo deberá investigar y aplicar los siguientes algoritmos:  

• SVD (Singular Value Decomposition)  
• t-SNE (t-Distributed Stochastic Neighbor Embedding)  
• UMAP (Uniform Manifold Approximation and Projection)  
• ICA (Independent Component Analysis)  

Para cada algoritmo, el grupo deberá desarrollar los siguientes puntos:  

1. Descripción teórica  
o Explicación del algoritmo y su objetivo principal.  
o Describir principales características y supuestos.  
o Establecer diferencias con otros métodos de aprendizaje no supervisado (por ejemplo, PCA).  

2. Usos y aplicaciones  
o Explicar principales usos del algoritmo en el análisis de datos.  
o Describir al menos dos áreas de aplicación.  

3. Aplicación práctica  
o Seleccione un conjunto de datos.  
o Implemente el algoritmo usando el conjunto de datos seleccionado.  
o Analice y explique los resultados obtenidos mediante tablas y/o gráficos.

EVALUACIÓN  

1. (20 puntos) Descripción teórica de los algoritmos.  
Se espera que el grupo:  
o Explique correctamente el funcionamiento de cada algoritmo.  
o Identifique su objetivo principal dentro del aprendizaje no supervisado.  
o Describa los supuestos básicos del método.  
o Destaque diferencias relevantes con otros algoritmos vistos en clase (por ejemplo, PCA).  
o Utilice un lenguaje técnico adecuado y coherente.  

La descripción debe tener claridad conceptual, precisión y comprensión real del algoritmo, no definiciones copiadas sin análisis.  

2. (15 puntos) Usos y aplicaciones  
Se espera que el grupo:  
o Identifique los principales usos de cada algoritmo.  
o Mencione al menos dos áreas de aplicación por algoritmo.  
o Relacione el algoritmo con problemas reales de análisis de datos.  
o Justifique por qué el algoritmo es adecuado para dichas aplicaciones.  

Los ejemplos deben ser pertinentes y debe existir conexión entre teoría y la práctica.  

3. (25 puntos) Implementación práctica  
Se espera que el grupo:  
o Aplique correctamente cada algoritmo a un conjunto de datos.  
o Describa el dataset utilizado y las decisiones tomadas (preprocesamiento, parámetros).  
o Ejecute el algoritmo sin errores conceptuales.  
o Presente resultados claros mediante tablas, gráficos o visualizaciones adecuadas.  

4. (20 puntos) Interpretación de resultados  
Se espera que el grupo:  
o Analice los resultados obtenidos de manera crítica.  
o Explique qué representan las componentes, proyecciones o separaciones obtenidas.  
o Discuta si los resultados son coherentes con el problema y el dataset.  
o Identifique limitaciones del algoritmo o del experimento realizado.  

Debe interpretar resultados mediante explicaciones claras de resultados y gráficos, no solo mostrarlos.
