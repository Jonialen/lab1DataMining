3. Análisis Estadístico

3.1 Distribución Normal en Variables Cuantitativas

Investigaremos si las variables cuantitativas principales siguen una distribución normal utilizando la prueba de Shapiro-Wilk (para una muestra, aunque el dataset es grande) y visualizaciones (Histogramas y Q-Q Plots). Debido al gran tamaño del dataset (19,883 filas), la prueba de Shapiro-Wilk suele ser muy sensible, por lo que nos apoyaremos más en histogramas y la prueba de Lilliefors.

# Selección de variables cuantitativas
cuantitativas <- datos[, c("budget", "revenue", "runtime", "popularity", "voteAvg", "voteCount")]

# Histogramas
par(mfrow = c(2, 3))
for (col in colnames(cuantitativas)) {
    hist(cuantitativas[[col]], main = paste("Histograma de", col), xlab = col, col = "lightblue")
}
# Pruebas de Normalidad (Lilliefors)
# Se contrasta la muestra contra una distribución normal con parámetros estimados
for (col in colnames(cuantitativas)) {
    #  res <- ks.test(scale(cuantitativas[[col]]), "pnorm")
    res <- lillie.test(cuantitativas[[col]])
    cat("\nVariable:", col, "\np-value (Lillie):", res$p.value, "\n")
}
